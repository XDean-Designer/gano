3开跑前检查

  • 手机号已录入。发码顾问、核销店员的号码必须预录并标明门店；未录入的打开小程序只会被当顾客。
  • 门店与项目已配好。GANO 门店、礼遇项目、券面文案与海报已就绪。
  • 档位与首批总量已核对。两档权益、金额、首批每档 1,000 份；选档页能看到「剩余 x/1000」。
  • 数据权限已分配。明确哪些账号是店长 / 运营，一线不开入口。
  • 全员知道：核销前必过「非会员确认」弹窗；领券页有截图提示；活动码都能用微信扫一扫拉起小程序。

4GANO 顾问：发码

顾客在 GANO 购卡满额，你把这单的丽妍礼遇送出去。

  1. 打开剑琅美遇，确认身份

    微信搜「剑琅美遇」或扫小程序码。号码在名单里会直接进「联盟合作」获客页，跳过首页是正常的。

  2. 按购卡金额选档

    选档页顶部写「请依据顾客本次在 GANO 的购卡金额选择档位」，两张卡：满 5,000 / 满 10,000。剩余 0 时整卡不可点。

  3. 亮出联盟礼遇码

    券面有权益、金额、项目与「请顾客用微信扫码领取」，底部「仅限现场扫码 · 请勿转发」。二维码每 3 分钟自动换新，不用手动操作。

  4. 请顾客当场扫码领取

    顾客用微信「扫一扫」即可，没装过也会直接拉起。领完券进顾客手机，同时同步到丽妍雅集。

  5. 交代三句话，收工

    三个月内有效、去之前提前 3 天电话预约、仅限本人一次用完。后续由顾客自行到店，你不参与核销。

发码别错这三处　① 满 10,000 不是二选一，是两项都做；② 已是丽妍会员的顾客不发券；③ 不要把码截图发给顾客或让其转发，转发无效也不计你的业绩。

5GANO 店员：核销

顾客拿丽妍发的联盟券到店，你核对、核销、安排服务。

  1. 接券，先看清档位

    顾客出示核销码（手机或截图均可）。先看券面项目与金额，心里有数再扫。

  2. 扫码

    底栏「扫码核销」进摄像头；或用微信「扫一扫」直接扫核销码，同样进核销流程。

  3. 过「核销前确认」弹窗

    弹窗正文：「请确认该顾客为本店非会员，且符合本次活动参与条件。确认后将完成核销。」按钮「取消核销 / 确认核销」。确认前先口头问一句。

  4. 核销成功，核对档案

    成功页显示券信息与顾客档案：脱敏手机、券号、丽妍雅集档位、领券与核销时间。档位仅店员可见，不要念给顾客听。

  5. 按券面权益服务

    V3–V5 档由顾客口头说做哪一项（¥198 洗剪吹 或 ¥218 法式头皮减压洗），系统不记录选项。V6–V10 档为日本玫丽盼全球化护理。

  6. 可选填服务备注，点「确认并返回」

    备注写服务情况，不是顾客评价。评价由顾客自己在手机上完成，店员不能代写。

弹窗出现时不要直接确认　系统不对接会员库，确认责任在你。顾客若已是本店会员或资格存疑，点「取消核销」先核实；取消后重扫即可，不产生记录。

6顾客侧

  • 扫码：微信扫礼遇码直接拉起小程序，登录后进活动页。
  • 领券：券页有金额、项目、有效期、核销码与券号；码下有「可将核销码截图保存，到店出示即可」。
  • 到店：出示核销码，核销后券变已核销，顾客直接接受服务。
  • 评价：核销后出现评分卡（1–5 星 + 选填文字），保存后回到找券页；评价只读同步到订单明细。
  • 订单：落在「我的订单 → 团购活动 → 已使用」，实付 ¥0。

9话术与禁忌

顾问发码

满 5,000

「您今天的购卡金额符合我们和丽妍雅集的联合礼遇，送您一次紫镜嘭弾护理，价值 ¥980。券我帮您领到手机里，到丽妍雅集出示就能用。三个月内有效，去之前提前 3 天打电话预约。」

满 10,000

「您这次两项都可以做：紫镜嘭弾护理和归元暖腹体验，都在丽妍雅集。一次预约可以一起安排，不用二选一。」

店员核销

弹窗前

「跟您确认一下，您目前还不是我们店的会员，对吧？这项礼遇是给新客的，确认后我就帮您核销。」

核销后

「已经核销好了。您今天想做洗剪吹还是法式头皮减压洗？」

禁忌

  • 不说档位名。「V3–V5」「V6–V10」只存在内部系统。
  • 不说「免费」。统一说「会员礼遇」「本次权益」。
  • 不对满 10,000 的顾客说「二选一」。
  • 不承诺券外的东西。不加项目、不延期、不折现、不换项、不补差价。
  • 不让拍照、转发、代领。仅限现场扫码。
  • 不代写评价、不手写核销、不补录核销。

10FAQ

顾客问

  • 没装过小程序能扫吗？能，微信「扫一扫」会直接拉起，再登录。
  • 能领两张 / 给朋友一张吗？不能，每人 1 次，仅限现场扫码。
  • 券过期了还能用吗？不能。系统不核销，门店另接待不进统计。

员工问

  • 打开怎么直接进获客页？可获客顾问冷启动直达，正常。
  • 底栏为什么没有「数据统计」？一线按设计隐藏，只有店长 / 运营可见。
  • 能先服务、事后补核销吗？不能。核销须在服务前完成，补录会破坏对账。
